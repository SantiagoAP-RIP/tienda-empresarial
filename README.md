# NovaMarket

Sistema web de tienda empresarial desarrollado en PHP, MySQL, HTML, CSS y JavaScript.

## Estructura

- `00-ingenieria-de-requerimientos/`: requisitos, actas e historias de usuario.
- `01-analisis/`: casos de uso, modelo de datos y especificacion funcional.
- `02-diseño/`: arquitectura, diagramas de clases y mockups.
- `03-desarrollo/src/`: codigo fuente PHP de la aplicacion.
- `04-pruebas/`: casos, evidencias y reporte de resultados.
- `05-implementacion/`: manual, instalacion y evidencias de despliegue.

## Ejecucion local

1. Instalar XAMPP con Apache, PHP y MySQL.
2. Copiar el proyecto dentro de `htdocs`.
3. Iniciar Apache y MySQL desde XAMPP.
4. Abrir `http://localhost/DesarrolloE/03-desarrollo/src/`.

La aplicacion crea la base de datos `tienda_empresarial`, sus tablas y datos iniciales automaticamente.

Usuario administrador inicial: `admin@novamarket.com`  
Contrasena inicial: `admin123`
