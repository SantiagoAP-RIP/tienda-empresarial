# Especificacion funcional

## Catalogo
El sistema lista los productos activos con nombre, descripcion, imagen, precio y stock.

## Usuarios
Los clientes pueden registrarse, iniciar sesion y cerrar sesion. El administrador tiene acceso al panel de gestion.

## Pedidos
Un cliente autenticado puede agregar productos al carrito y confirmar el pedido. El sistema valida el stock antes de guardar la compra.

## Administracion
El administrador puede crear, editar y desactivar productos, ademas de revisar alertas de stock bajo.
