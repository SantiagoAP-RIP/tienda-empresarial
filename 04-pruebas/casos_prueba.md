# Casos de prueba

| ID | Caso | Resultado esperado |
| --- | --- | --- |
| CP-01 | Abrir el catalogo | Se muestran productos activos con imagen y precio. |
| CP-02 | Registrar usuario | El usuario queda creado y puede iniciar sesion. |
| CP-03 | Agregar producto al carrito | El producto aparece con su cantidad y subtotal. |
| CP-04 | Confirmar compra | Se crea el pedido y se descuenta el stock. |
| CP-05 | Acceder al panel administrador | Solo un usuario con rol admin puede entrar. |
