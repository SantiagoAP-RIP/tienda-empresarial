# Guia de instalacion

1. Instalar XAMPP.
2. Copiar esta carpeta en `C:\xampp\htdocs\`.
3. Iniciar Apache y MySQL.
4. Visitar `http://localhost/DesarrolloE/03-desarrollo/src/`.
5. La primera ejecucion crea la base de datos y los datos iniciales.

Si MySQL utiliza credenciales distintas, actualizar los valores de conexion al inicio de `03-desarrollo/src/conexion.php`.
