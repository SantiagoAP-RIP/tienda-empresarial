# Historias de usuario

- Como cliente, quiero consultar un catalogo de productos para elegir articulos.
- Como cliente, quiero registrarme e iniciar sesion para realizar pedidos.
- Como cliente, quiero agregar productos al carrito y confirmar la compra.
- Como cliente, quiero consultar mis pedidos anteriores.
- Como administrador, quiero gestionar productos e inventario.
- Como usuario, quiero consultar el chatbot para resolver dudas frecuentes.
